研究方法摘要

01

資料蒐集

以 Python 爬蟲擷取 104 人力銀行公開職缺，保留含薪資範圍記錄，移除異常值後取得有效訓練樣本。

02

特徵工程

職務名稱 TF-IDF 向量化、K-Means 職務分群、類別欄位 Target Encoding、薪資年資段正規化。

03

模型訓練

以 CatBoost、LightGBM、XGBoost 分別訓練最低薪與最高薪預測子模型，共六個模型，以 MAE、RMSE、R² 評估。

04

系統整合

Python Flask API 提供預測端點，Next.js 前端整合即時預測介面、視覺化圖表與研究展示頁面。
